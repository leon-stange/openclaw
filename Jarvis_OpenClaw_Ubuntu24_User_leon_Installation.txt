JARVIS / OPENCLAW AUF UBUNTU 24.04 NEU AUFSETZEN
=================================================

Ziel
----
Diese Anleitung setzt den aktuellen Jarvis-Stand auf einem frisch installierten
Ubuntu-24.04-Server für den Benutzer "leon" neu auf.

Geplanter Stand:
- OpenClaw 2026.9.8
- Benutzer: leon
- OpenAI / ChatGPT Login
- Modell: openai/gpt-5.6-sol
- WhatsApp
- WhatsApp-Allowlist
- OpenClaw-Owner-Allowlist
- ElevenLabs TTS
- MeowCaller
- WhatsApp-Anruf an den aktuellen Absender
- eigenes Plugin "whatsapp-call-contact"
- freigegebene Kontakte, z. B. Annka
- systemd Autostart ohne SSH-Login

WICHTIG
-------
1. OpenClaw immer als Benutzer "leon" installieren und ausführen.
2. "sudo" nur für Systempakete, Go-Installation und loginctl verwenden.
3. Port 18789 NICHT öffentlich im Internet freigeben.
4. API-Keys niemals direkt als Klartext in Shell-Befehle schreiben.
5. Telefonnummern unten durch echte Werte ersetzen.
6. Die Windows-spezifischen OpenClaw-Patches werden unter Ubuntu NICHT benötigt.

2. OPENCLAW 2026.9.8 INSTALLIEREN
=================================================

curl -fsSL --proto '=https' --tlsv1.2 https://openclaw.ai/install.sh | bash -s -- --version 2026.9.8 --no-onboard --verify

exec "$SHELL" -l

3. OPENAI / CHATGPT LOGIN
=================================================

Für einen Headless-Server empfiehlt sich Device-Code-Login:

Den angezeigten Link auf deinem normalen PC öffnen und den Code eingeben.

Danach prüfen:

openclaw models auth list --provider openai

6. WHATSAPP ALLOWLIST + OWNER EINRICHTEN
=================================================

WICHTIG:
Bei "read -rp" ist der Text vor der Eingabe nur die Aufforderung.
Die Telefonnummer muss DANACH wirklich eingegeben werden.

Richtig:

read -rp "Deine private WhatsApp-Nummer im Format +49...: " OWNER_NUMBER

Jetzt die Nummer eingeben, z. B.:

+49DEINE_NUMMER

Zur Kontrolle:

echo "$OWNER_NUMBER"

Es muss deine Nummer ausgegeben werden.

Konfigurationsdatei erstellen:

cat > /tmp/jarvis-whatsapp.json <<EOF
{
  "channels": {
    "whatsapp": {
      "enabled": true,
      "dmPolicy": "allowlist",
      "allowFrom": [
        "$OWNER_NUMBER"
      ],
      "groupPolicy": "disabled",
      "mediaMaxMb": 50,
      "actions": {
        "calls": true
      }
    }
  },
  "commands": {
    "ownerAllowFrom": [
      "whatsapp:$OWNER_NUMBER"
    ]
  }
}
EOF

Dry-Run:

openclaw config patch --file /tmp/jarvis-whatsapp.json --dry-run

Wenn erfolgreich:

openclaw config patch --file /tmp/jarvis-whatsapp.json

Prüfen:

openclaw config get channels.whatsapp.allowFrom --json
openclaw config get commands.ownerAllowFrom --json

Erwartet ungefähr:

[
  "+49..."
]

und:

[
  "whatsapp:+49..."
]

8. GO 1.27 INSTALLIEREN
=================================================

Architektur erkennen:

case "$(dpkg --print-architecture)" in
  amd64) GOARCH="amd64" ;;
  arm64) GOARCH="arm64" ;;
  *) echo "Nicht unterstützte Architektur: $(dpkg --print-architecture)"; exit 1 ;;
esac

Go herunterladen:

cd /tmp
curl -fLO "https://go.dev/dl/go1.27.0.linux-${GOARCH}.tar.gz"

Installieren:

sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf "go1.27.0.linux-${GOARCH}.tar.gz"

PATH dauerhaft setzen:

echo 'export PATH=/usr/local/go/bin:$HOME/.local/bin:$PATH' >> ~/.profile

Für die aktuelle Sitzung:

export PATH=/usr/local/go/bin:$HOME/.local/bin:$PATH

Prüfen:

go version

Erwartet ungefähr:

go version go1.27.0 linux/amd64

oder:

go version go1.27.0 linux/arm64

13. FREIGEGEBENEN KONTAKT EINRICHTEN
=================================================

Eigene Nummer einlesen:

read -rp "Deine Nummer A im Format +49...: " OWNER_NUMBER

Kontakt-Nummer einlesen:

read -rp "Nummer des freigegebenen Kontakts im Format +49...: " CONTACT_NUMBER

Beispiel-Konfiguration für Annka:

cat > /tmp/jarvis-contact-plugin.json <<EOF
{
  "plugins": {
    "entries": {
      "whatsapp-call-contact": {
        "config": {
          "authorizedCaller": "$OWNER_NUMBER",
          "contacts": [
            {
              "name": "Annka",
              "phone": "$CONTACT_NUMBER",
              "aliases": [
                "Annka",
                "Ann-Kathrin"
              ]
            }
          ],
          "voiceId": "QY3Oz57TOFa67IL9gWWV",
          "model": "eleven_multilingual_v2",
          "accountId": "default",
          "meowcallerPath": "/home/leon/.local/bin/meowcaller",
          "maxMessageChars": 450,
          "maxCallsPer10Minutes": 5
        }
      }
    }
  }
}
EOF

Dry-Run:

openclaw config patch --file /tmp/jarvis-contact-plugin.json --dry-run

Übernehmen:

openclaw config patch --file /tmp/jarvis-contact-plugin.json

Plugin aktivieren:

openclaw plugins enable whatsapp-call-contact

Prüfen:

openclaw plugins inspect whatsapp-call-contact --runtime

Erwartet:

Status: loaded

Tools:
whatsapp_call_contact
whatsapp_call_contacts

=================================================
15. ELEVENLABS-API-KEY SICHER FÜR SYSTEMD HINTERLEGEN
=================================================

Environment-Datei vorbereiten:

mkdir -p /home/leon/.openclaw
touch /home/leon/.openclaw/gateway.systemd.env
chmod 600 /home/leon/.openclaw/gateway.systemd.env

Alte Einträge entfernen, falls vorhanden:

sed -i '/^ELEVENLABS_API_KEY=/d' /home/leon/.openclaw/gateway.systemd.env
sed -i '/^PATH=/d' /home/leon/.openclaw/gateway.systemd.env

API-Key verdeckt eingeben:

read -rsp "ElevenLabs API Key: " ELEVENLABS_API_KEY
echo

Key speichern:

printf 'ELEVENLABS_API_KEY=%s\n' "$ELEVENLABS_API_KEY" >> /home/leon/.openclaw/gateway.systemd.env

PATH für MeowCaller und Go setzen:

printf 'PATH=/home/leon/.local/bin:/usr/local/go/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin\n' >> /home/leon/.openclaw/gateway.systemd.env

Variable aus aktueller Shell löschen:

unset ELEVENLABS_API_KEY

Dateirechte erneut setzen:

chmod 600 /home/leon/.openclaw/gateway.systemd.env

Gateway neu laden:

systemctl --user daemon-reload
systemctl --user restart openclaw-gateway.service

=================================================
20. JARVIS-PERSÖNLICHKEIT VOM WINDOWS-SYSTEM ÜBERNEHMEN
=================================================

NICHT den kompletten Windows-Ordner:

C:\Users\Jarvis\.openclaw

blind nach Ubuntu kopieren.

Stattdessen gezielt die Workspace-/Persönlichkeitsdateien übernehmen, z. B.:

SOUL.md
AGENTS.md
USER.md
MEMORY.md

sowie weitere von dir angepasste Agent-Dateien.

Damit bleibt die Persönlichkeit erhalten, ohne Windows-Pfade oder Windows-spezifischen Zustand mitzunehmen.

22. FEHLERSUCHE
=================================================

Gateway läuft nicht:

openclaw gateway status --deep

systemd-Status:

systemctl --user status openclaw-gateway.service --no-pager

Letzte Logs:

journalctl --user -u openclaw-gateway.service -n 100 --no-pager

Live-Logs:

journalctl --user -u openclaw-gateway.service -f

OpenClaw Diagnose:

openclaw doctor

Plugin-Diagnose:

openclaw plugins doctor

WhatsApp prüfen:

openclaw channels status --channel whatsapp --probe

Owner prüfen:

openclaw config get commands.ownerAllowFrom --json

Wenn dort nur:

[
  "whatsapp:"
]

steht, wurde OWNER_NUMBER leer gespeichert.

Dann erneut:

read -rp "Deine private WhatsApp-Nummer im Format +49...: " OWNER_NUMBER

Nummer wirklich eingeben.

Danach /tmp/jarvis-whatsapp.json neu erzeugen und erneut patchen.


=================================================
23. SICHERHEIT
=================================================

- Port 18789 nicht öffentlich öffnen.
- Gateway möglichst auf 127.0.0.1 lassen.
- ElevenLabs-Key nicht in Chat, Screenshots oder Shell-History posten.
- wa-voip.db privat halten.
- /home/leon/.openclaw nur für leon zugänglich lassen.
- Nur deine eigene Nummer unter commands.ownerAllowFrom eintragen.
- Im Contact-Call-Plugin nur ausdrücklich erlaubte Kontakte hinterlegen.
